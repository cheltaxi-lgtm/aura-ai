# Матрица судьбы Zovus — методология

**methodology_id:** `zovus-matrix-22-v1`  
**calculation_version (live):** `matrix-v4`  
**renderer_version (live):** `matrix-svg-v5`

Это **не** лицензированная «официальная Матрица Ладини».
Zovus фиксирует одну воспроизводимую систему 22 энергий по открытым учебным источникам
и больше не смешивает школы внутри одного калькулятора.

Продуктовое имя: **Матрица судьбы Zovus · система 22 энергий**.

---

## 1. Glossary

| термин | значение |
| --- | --- |
| точка | одно число 1–22 в конкретной позиции схемы |
| линия рода | набор точек прямого (родового) квадрата |
| канал | упорядоченный путь по уже посчитанным точкам |
| предназначение / зона комфорта | центр X |
| период | энергия дискретного 5-летнего сектора возрастного пояса |
| прогноз | аркан года / месяца — отдельный namespace `period.*` |
| аналитический акцент Zovus | `focusKey` и любые score — не канон схемы |

## 2. Reducer

**Выбран вариант B: сложение цифр. Число 22 не сворачивается.**

```
reduce(n):
  n = |trunc(n)|
  while n > 22:
    n = sum of decimal digits of n
  if n == 0: return 22
  return n
```

Доказанные учебные примеры (не из кода Zovus):

| вход | результат | источник |
| --- | --- | --- |
| 22 | 22 | matrica-sudbyy.ru; destinynums.com |
| 24 | 6 | matrica-sudbyy.ru |
| 28 | 10 | matrica-sudbyy.ru |
| 31 | 4 | matrica-sudbyy.ru; destinynums.com (26→8 тот же принцип) |
| 38 | 11 | matrica-sudbyy.ru (7+9+22) |
| 42 | 6 | matrisa-sudbi.ru (15+8+19) |
| 48 | 12 | matrisa-sudbi.ru (центр 15.08.1990) |

**Вариант A (31 → 9 через 31−22)** — это Zovus `matrix-v3`. Он **не** совпадает с учебной 22-энергетической школой. Сохраняется только для replay старых отчётов.

Расхождение школ:

| школа | 31 | 42 | 23 | 41 |
| --- | --- | --- | --- | --- |
| 22 энергии / digit-sum (`zovus-matrix-22-v1`) | 4 | 6 | 5 | 5 |
| Zovus subtract-22 (`matrix-v3`) | 9 | 20 | 1 | 19 |

## 3. Базовые формулы (личное / диагональный квадрат)

Топология Zovus (октограмма, не учебный «квадрат на бумаге»):

- A = left = характер
- B = top = небо
- C = right = материя
- G = bottom = земля / корень хвоста

Числа A/B/C/G/X совпадают с учебной четвёркой углов + центром.
Разница только в повороте схемы (ромб vs неповёрнутый квадрат).

| id | название | формула | reducer | откуда | смысл | coordinate id | source |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A | Характер | day | digit-sum | дата | врождённые реакции | `outer.left` | matrisa-sudbi.ru; matrica-sudbyy.ru |
| B | Небо | month | digit-sum | дата | духовное / месяц | `outer.top` | то же |
| C | Материя | digitSum(year) | digit-sum | дата | внешний мир / год | `outer.right` | то же |
| G | Земля / корень хвоста | A+B+C | digit-sum | A,B,C | нижняя точка напряжения | `outer.bottom` | то же (D) |
| X | Зона комфорта | A+B+C+G | digit-sum | A,B,C,G | центр | `center` | то же |

Golden:

- `1990-08-15` → A=15 B=8 C=19 G=6 X=12 (matrisa-sudbi.ru)
- `1984-09-07` → A=7 B=9 C=22 G=11 X=13 (matrica-sudbyy.ru)

## 4. Внутренние точки и прямой квадрат

| id | название | формула | coordinate id | source |
| --- | --- | --- | --- | --- |
| love | Отношения | A+X | `horizontal.left` | сосед + центр |
| sky | Дух / небо внутреннее | B+X | `vertical.top` | сосед + центр |
| money | Деньги | C+X | `horizontal.right` | сосед + центр |
| earth | Задача / середина хвоста | G+X | `vertical.bottom` | сосед + центр |
| AB | Таланты | A+B | `outer.topLeft` | прямой квадрат |
| BC | Род матери | B+C | `outer.topRight` | прямой квадрат; возраст 30 |
| CG | Род отца | C+G | `outer.bottomRight` | прямой квадрат; возраст 50 |
| GA | Родовая точка 70 | G+A | `outer.bottomLeft` | прямой квадрат; возраст 70 |
| tailTip | Остриё хвоста | G+earth | `karmicTail.tip` | трёхточечный хвост |

**Таланты = AB.** Это вершина прямого квадрата, не `B+X` (дух).

**Род отца = C+G**, не A+C. A+C не является вершиной прямого квадрата.
`matrix-v3` хранил paternal = A+C как отдельный `maleLine.head` — это запись v3, не часть `zovus-matrix-22-v1`.

## 5. Линии рода

### Женская линия

1. AB — таланты / верхний левый угол прямого квадрата  
2. B — небо / месяц  
3. BC — род матери / верхний правый угол  

### Мужская линия

1. A — характер / день  
2. GA — нижний левый угол прямого квадрата  
3. CG — род отца / нижний правый угол  
4. C — материя / год  

Симметрия: женская линия читается по верхней стороне прямого квадрата, мужская — по нижней + личным A/C.
Отдельный `femaleLine.head` не нужен: BC уже вершина.
Отдельный `maleLine.head` для v4 не нужен: CG уже вершина.

## 6. Каналы

Канал — маршрут по уже посчитанным точкам. Движок не подбирает «удобные» точки.

| id | label | pointIds | methodology | rendererPathIds |
| --- | --- | --- | --- | --- |
| love | Канал отношений | A, love, X, money | горизонталь «отношения–деньги» | left → love → center → money |
| money | Денежный канал | sky, X, money, earth | вертикально-правый денежный контур | sky → center → money → earth |
| male | Мужская линия рода | A, GA, CG, C | прямой квадрат | left → BL → BR → right |
| female | Женская линия рода | AB, B, BC | прямой квадрат | TL → top → TR |
| skyEarth | Небо — Земля | B, sky, X, earth, G | вертикальная ось | top → sky → center → earth → bottom |
| karmicTail | Кармический хвост | earth, G, tip | трёхточечный хвост | earth → bottom → tip |

Почему money входит в love-канал: в 22-энергетической октограмме горизонталь — одна ось отношений и денег. Это не ошибка и не «случайная» точка.

## 7. Возрастной пояс

Энергия считается **только** для точек 0, 5, 10, …, 80.
Промежуточный календарный возраст (например 37) **не** получает отдельную энергию.

UI: `Период 35–40 лет`, никогда «Возраст сейчас: 35» для 37-летнего.

Сектор 60 лет математически совпадает с нижней вершиной (G).
Координата энергии = истинный угол сектора.
Смещение −112° допускается только для подписи/бусины, не для семантики.

## 8. Период / прогноз (отдельный namespace)

Не входят в immutable birth-core.

| id | формула | namespace |
| --- | --- | --- |
| period.year | A + B + digitSum(asOf.year) | `period.year` |
| period.month | period.year + calendarMonth | `period.month` |

Школы расходятся в формуле года. Zovus фиксирует эту пару как **period analytics**
системы `zovus-matrix-22-v1`, не как часть рождения.

`asOf` обязан быть сохранён в snapshot. Без него диаграмма не имеет права
пересчитывать год/месяц/период «на сегодня».

## 9. Арканы 8 / 11

Для `zovus-matrix-22-v1` / `matrix-v4`:

- 8 — Справедливость  
- 11 — Сила  

Марсельская традиция 22-энергетических калькуляторов (calc.myarcana.life, matrisa-sudbi.ru, numerolog.ru).

Колода Таро Zovus **не меняется**: Rider–Waite 8 Сила / 11 Справедливость.

`matrix-v3` и старше в сохранённых текстах остаются на Rider–Waite именах.

## 10. Zovus derived analytics

Не часть учебной схемы. В UI: «аналитический акцент Zovus».

- `focusKey` / `focusLabel` — вес резонанса периода с точками схемы  
- compatibility `score` / pairComfort / pairYear  
- year-forecast opportunity/caution month lists

## 11. Чего в методике нет

Не изобретаем: чакры, внешние generation-дуги, отдельный female head, энергию каждого года жизни.
